# A股主升浪因子映射 v1.1

本说明把美股12项研究因子适配到中国A股，用于研究20—40个交易日的主升浪候选。优先核验盈利与订单、板块广度、相对强弱和突破质量；利率、信用、融资拥挤属于环境及风险条件。

这是研究规格，尚未接入现有 `macro_regime` / `macro_selection` 运行入口。现有 v1.1 冻结规则、CSI300核心选择门槛和纸面记录保持原定义。机器可读数据字典见 [a-share-factor-mapping.json](a-share-factor-mapping.json)，不包含当期行情、候选推荐或已校准的评分权重。

## 12项对应关系

| 美股原始因子 | 中国指标 | 计算口径与适配边界 |
|---|---|---|
| 实际利率20日变化 | 10年中债国债收益率、DR007与7天逆回购政策利率的差 | 名义收益率20日变化以bp表示；资金利差单列。国债收益率减CPI仅为事后代理，不能当作TIPS隐含实际利率。DR007与FDR007是不同序列，不混接 |
| 高收益债OAS变化 | AA／AA+产业债信用利差 | 固定评级、期限、行业及估值方法，减同期限国债收益率，观察20日变化；不等价美国高收益OAS |
| EPS修正广度 | 同财年一致预期EPS净上修广度 | 30日内上修家数减下修家数，除以有效公司数；财年、预测源和样本固定。公告增长、订单增长、评级上调另列，不代填EPS修正 |
| 自由现金流率改善 | TTM自由现金流率同比变化 | 合并口径：经营现金流减购建固定资产、无形资产和其他长期资产现金，再除以营收；同比变化用百分点。理财赎回、融资及资产出售不作为正常FCF |
| PB净杠杆分位 | 融资拥挤度、行业ETF份额变化 | 融资余额／自由流通市值的252日分位、20日变化；20日融资买入减偿还另列。ETF份额变化单列，不能冒充机构净仓位 |
| PB总杠杆分位 | 无可靠公开等价项 | 与融资拥挤度合并以避免重复计权；用独立的解禁／减持／质押风险因子补充，不制造中国PB总杠杆 |
| 个股IV分位 | 对应指数／ETF期权30日平值IV分位 | 相邻期限总方差插值构造恒定30日IV，取252日分位。个股ATR／RV为另一类指标，不代填个股IV |
| IV／RV比值 | 同一指数／ETF的IV／RV | 分子30日年化IV，分母20日日对数收益样本标准差乘√252；标的和时点一致，RV为0或无期权链时留空 |
| AI对非AI的相对收益 | 个股、行业、市场的多层相对强弱 | 个股20日收益减沪深300收益；个股减固定同业池收益；目标板块减非重叠对照池收益，三项分别计算，不混成同一序列 |
| 放量突破广度 | 固定行业池放量突破率、MA60上方比例 | 收盘高于此前20日最高价且成交量≥此前20日均量1.2倍的公司比例；高点与均量窗口均排除当天，非全市场扫描须注明池范围 |
| 已核实催化数量 | 官方未来事件与已发布兑现证据 | 未来10自然日重大事件按同一事件去重；已公布订单、获批、业绩修正另列，记录对收入／利润的量化影响。旧公告不重复计为未来催化 |
| 资本开支修正 | 下游客户同财年资本开支／扩产指引变化 | 固定客户池、统一币种、可比指引中点变化；供应商自身资本开支单列，结合订单、合同负债、利用率和现金回报，不将扩产直接当盈利利好 |

来源：利率与信用取自[中债](https://yield.chinabond.com.cn/cbweb-cbrc-web/cbrc/showCbrc)、[中国货币网](https://www.chinamoney.com.cn/chinese/index.html)与[人民银行](https://www.pbc.gov.cn/)；融资取自[上交所明细](https://www.sse.com.cn/market/othersdata/margin/detail/)及[深交所](https://www.szse.cn/)；公司财务、事件和减持解禁公告取自[巨潮资讯](https://www.cninfo.com.cn/)和交易所。完整有时点历史的一致预期通常需要Wind／Choice等数据服务，不能从今天的预测值还原过去。

## 六项A股补充因子

| 因子 | 主要字段 | 用途 |
|---|---|---|
| 趋势与平台位置 | 收盘／MA20／MA60／MA200、均线斜率、距此前60日高点 | 区分上涨趋势、平台蓄势与下跌反弹 |
| 突破质量 | 突破幅度、当日量／此前20日均量、收盘区间位置、突破后的平台保持 | 核验价格承接；突破后的信息只在其实际发生后可用 |
| 追价与回撤 | MA20乖离、Wilder RSI14、ATR14／股价、近期最大回撤 | 单列过热、波动和结构风险，不把大涨自动加为机会分 |
| 流通筹码供给 | 自由流通市值、换手率、未来解禁比例、已公告减持与质押 | 观察所需资金规模和新增供给；解禁不等于实际卖出 |
| 盈利兑现质量 | 订单、扣非利润、经营现金流、应收、存货及利用率变化 | 核验题材是否转化成利润与现金；同比、环比、相对年初变化分别标记 |
| 交易可执行性 | 成交额、停牌、涨跌停与盘口、冲击成本、T+1 | 区分研究信号与可成交净收益；不能假设涨停买到或跌停卖出 |

这些字段可能与原12项相关。未完成增量样本外验证前，不重复计权，不宣称“资金流”代理恢复了真实机构买卖。

## 数据与计算约定

- 每项输入保存 `observed_at`（数据对应时点）、`available_at`（首次可知时点）、`fetched_at`（抓取时点）、时区、来源、序列ID、单位、定义版本及核验状态。网页抓取时间不替代行情或公告时间。
- 固定股票池、成分、权重、生效日期及对照池；股票池不得事后仅保留赢家。成分变化与历史ST、停牌和退市状态必须按当时记录。
- 利率原始值为百分数时，变化乘100转为bp；收益超额与利润率变化以百分点表示；分位为0—100。252日分位至少200个有效观测，样本不足留空。
- 同财年EPS预测避免跨年滚动造成伪修正；原NTM定义与同财年定义分别版本化。EPS接近0或负值时不套用普通百分比变化，单列转亏／转盈。
- 财务用合并报表与当时已发布版本。TTM流量可用“本期累计＋上年全年－上年同期累计”拼接，三项必须有可比口径。半年现金流代理不冒称TTM；并表、重述、理财现金与公司经调整FCF分别核验。
- 价格必须统一复权／总回报口径；供应商前复权价格只能明确标为代理。现金分红、拆并股、送转和股本变化须核对，量的调整独立处理。
- 缺失值保持 `null`，记录原因；不填0或50。期权IV不存在时，指数IV与个股ATR／RV分别显示。融资比率受股价分母变化影响，余额变化与市值变化需拆开解释。
- 北向等资金数据按实际披露频率和定义使用；不把持仓变化、客户端“主力净流入”、ETF价格涨跌当成同一种真实买盘。

## 策略与验证边界

事件重估／订单兑现路径与趋势内超卖反弹分别建模。LRCX式反弹条件为收盘>SMA200、Wilder RSI2≤20、3日收益为负，不自动认定进入主升浪；WDAY原始参数未知时保持未知。

主升浪研究可分别定义10交易日净收益≥10%、20日≥20%、40日≥30%的结果标签，先冻结入场、退出、成本与标签窗口。它们是独立研究目标，不是承诺回报。入场使用下一可交易时点，回测按 `available_at` 截断；新持仓遵守T+1，未成交和无法退出情形另行保留。

主升浪的顺序建议为：盈利或订单改善 → 行业参与扩大 → 个股相对强弱领先 → 放量突破且乖离受控 → 供给与成交风险可承受。这是研究结构，权重、方向和阈值需比较简单基准及增量样本外效果；原美股权重与阈值不直接搬用。

低融资分位不能证明将有回补买盘；低IV不提供上涨方向；资本开支上修不保证利润率或现金流改善。总机会分、候选相对排序、绝对买入条件和独立风险警报分别报告。未通过收益有效性验证时，不输出暴涨概率，不把模型弃权解释为自动卖出信号。

本次同步为文档和机器可读研究规格。JSON字段与文档一致性检查不证明投资效果，也不表示数据采集、因子计算或交易入口已经实现。
