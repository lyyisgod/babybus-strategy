# VICR / LRCX / WDAY：用户指定优先参考策略

建立日期：2026-09-21。适用：美股短线、盘后/夜盘/盘前买入、次日或数日爆发、趋势内回撤反弹。用户要求：“把你建模分析 vicr、lrcx、wday 的策略，保存本地，优先参考。”

这是优先研究入口，不是已认证高胜率系统。以后优先复用方法，并用当次最新数据筛选新的股票；不因案例成功就机械重复买这三个代码。统一量化框架、TSLA 用户规则、行业背景时效和不自动交易约定继续适用。

2026-09-23 起重新训练或筛选时，先执行[防泄露与过拟合建模约束](../防泄露与过拟合建模约束.md)。旧固定股票池的历史比例与概率只可作为有偏的条件排序；未取得逐日点时股票池及新的未碰过审计段前，不得输出经验证的“高概率暴涨”判断。

## 一页执行顺序

1. **先定义用户真正要赚的那段收益。** 记录决策时点、拟入场时段/价格、预期退出时点。区分前收→次日高、次日开盘→高、真实盘后买价→次日高、真实买价→退出。触及 +5% / +10% 不等于最终赚到该收益。
2. **同时跑两类优先方法。** A 为 VICR 型“具有业绩弹性的股票＋已知催化＋右尾收益排名”，B 为 LRCX 型“长期趋势仍在＋短期过度回撤”。分别报告，不把二者强行揉成一个手工胜率。
3. **先冻结股票池和模型，再看结果。** 保存全部候选、落选、来源时点和参数。训练、校准、评估按时间隔离；结果未成熟的标签不进入训练。跨股票共同市场冲击用日期块处理，避免把股票日数量当独立样本量。
4. **财务含量优先。** 指引上修、真实订单、许可费兑现、利润率改善，通常比参会/演示更值得核验；核验公告是否已经发布、合同金额、量产/交付时间与现金回款。这个顺序是分析原则，不是已测得的概率加权。
5. **技术排序和可交易性分开。** 同时看相对强弱、成交量、均线位置、ATR、开盘后延续、下探风险，以及当前已涨幅度。大波动股票可能更易触及上涨目标，也更容易先止损。
6. **明确给相对首选，同时交代绝对门槛。** 用户要求“必须选一只”时可以给条件性投机首选，但不能调高原模型概率，也不能把原来的不买结论改写成强确认。用户允许空仓时，证据不够可以不交易。
7. **以最新可成交价重算。** 报价须有时间、盘前/盘后/夜盘身份；无买卖盘口就明确未知。给入场上限、失效条件、最长持有期和从实际买价计算的目标，不能把已发生的跳涨当潜在收益。价位过期就重算，未通过不等于股价一定跌。
8. **持续登记所有结果。** 推荐时证据与后来发生的公告分别保存，区分真实用户交易、条件方案和模拟成交；保留没有上涨、提前止损、未成交及用户未买的案例。
