## 保留原判断的边界

同一股票同一目标常规盘合并，刷新版本不删除；从首次首选报价起算，不用事后更低报价替换。凌晨研究的下一常规盘可能是当天，周末则按 NYSE 日历。VICR 9/21 盘前、当晚的新报价，以及 IREN 下午与夜盘版本分别保留。

AAOI 9/30 原建议等待，随后上涨单列错失机会；WDAY 原始推荐尚未定位，不能用 WDC 替代。LRCX 最长 20 日规则及 COHR 等较长持有期仅作独立方法参考，不并入隔夜命中。10/2、10/3 的周一候选保持未到期；周五计划失效与周一结果是两件事。

原报告中的条件买点、曾输出的模型数字和概率只是当时的记录，未经重新认证。既不改写旧预测，也不作为当前买入建议。实际成交及退出未知的保持未知；高点价格不能替代成交收益。

脱敏仅删除无关个人账户信息并匿名化本机路径，保留位置与原文件校验值。大型重复缓存与无关材料列入省略清单；完整候选排序、筛选门槛、模型定义、落选原因及已有复盘实际使用的行情输入保留。历史代码在 sources 中供查阅，部分外部依赖/缓存未打包，不作为可直接运行的新策略。

这些旧研究使用过不同模型，属于参考案例，不是冻结 macro_regime v1.1 的验证样本；不改变其阈值，不合并纸面 N，不由此推算未来胜率。
